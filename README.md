# Description
This projects aims to introduce the user to net configuration.
<br>
To make sure the user understands the basics, 10 exercise configurations must be added to this Git repository. Using a provided tool, the user must be able to solve 3 out of those 10 exercises in under 15 minutes.

# Instructions
This project requires the user to download the resources, complete 10 exercises and export the configuration of the solutions to upload them to the Git repository.

To complete the exercises, the user must download and extract the zipped folder in the desired destination.

Once the folder has been extracted, open the file 'index.html' using a web browser and choose either *Training* or *Evaluation*. Then add your intra 42 *login* and press the button *Start*.

Click the *Check again* button to verify if the configuration is correct or not. If there is any error, the problem will be displayed in the bottom-right corner of the window.

Click the *Get my config* button to download the configuration whenever you need to. It will be usefull to turn in the assignment.

Click the *Next level* button to continue to the next level. NOTE: this button will only appear when you have successfully completed a level.
